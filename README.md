# ⚖️ 소비 재판소

"이거… 내가 왜 샀지?" — 후회 소비 한 건을 사진으로 기소하면, AI 판사가 6~8개 질문으로
심문하고 **유·무죄 판결 + 소비 유형(16종)**을 선고하는 웹 법정.

> 2026 제2회 호남권 SW중심대학 LLM 해커톤 (AWS Kiro) — 팀 E1-T07

## 재판 절차
1. **소환장** — 이메일로 피고인 출석 확인 (비밀번호 없음)
2. **기소** — 결제내역 캡처·영수증·제품 사진 1장 제출 → Bedrock 비전이 조서 작성
3. **심문** — 판사가 물건을 콕 집어 심문 (질문 문구는 Bedrock이 사건 맞춤 생성, 판사 음성 TTS)
4. **판결** — 도장 쾅. 유죄/집행유예/무죄 + 소비 MBTI 16유형 + 형량(절약 미션)
5. **전과 기록** — 판결받은 소비들이 이메일 앞으로 쌓이는 회고 아카이브

## 설계 원칙
**판정은 룰, 문장은 LLM.** 축 점수·유죄 점수·유형 확정은 전부 서버의 결정적 룰이고,
Bedrock(Claude Sonnet 5)은 ①사진→조서 ②질문 재작성 ③판결문 산문 3곳만 맡는다.
LLM이 전부 실패해도 재판은 기본 질문 뱅크와 템플릿 판결문으로 끝까지 진행된다.

## 스택
순수 HTML/CSS/JS · FastAPI · SQLite · AWS Bedrock + S3 · EC2(8501)
