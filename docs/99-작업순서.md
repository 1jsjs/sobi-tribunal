## 배포 (팀 결정 8/28: 로컬 완성 우선 — 그 전엔 서버에 올리지 않는다)
B301~F305를 전부 로컬 MOCK_AI=1로 완성·검증한 뒤, **배포는 마지막에 한 번**만 한다.
단, MOCK은 Bedrock 요청 형식·판단을 검증하지 못하므로(실측 2회 당함) 배포 직후
①비전에 실제 캡처 3장 ②질문 스타일링 1회 ③판결문 1회를 반드시 실서버로 돌려보고
app.log의 "Bedrock 호출 실패"가 0인지 확인한다. 이 검증 시간 30~60분을 마감 전에 확보할 것.
```
ssh -i hackathon-e1-t07-key.pem ubuntu@18.135.105.80
cd ~/tribunal-v3 (git clone 또는 pull)
~/appenv/bin/pip install -r requirements.txt
lsof -ti:8501 | xargs kill -SIGTERM
cd ~/tribunal-v3 && nohup ~/appenv/bin/python -m uvicorn main:app --host 0.0.0.0 --port 8501 </dev/null >app.log 2>&1 &
grep -c "Bedrock 호출 실패" app.log   # 배포 후 필수 확인
```
주의: v2가 ~/receipt-tribunal에서 8501을 점유 중 — v3 전환은 팀 합의 후에.
