[F307] 판결문 섹션 UI + 법정 레이아웃·가독성 패키지 (팀 피드백 8/28 밤, 발표장 기준)

api-contract §판결(새 구성)을 다시 읽어라. B307이 crime·reasoning 필드를 이미 제공한다.
원칙: 발표장 뒷자리에서도 읽혀야 한다. 애매하면 키운다.

1. 판결문 화면 — 자유 산문 대신 **라벨 섹션 조립** (양피지 카드 안):
   피고인(이메일 @ 앞부분) / 죄명(crime, 크고 굵게 — 이 화면의 헤드라인) /
   주요 증거(evidence 불릿 목록) / 재판부 판단(reasoning) /
   최종 판결(guiltLabel 강조 + sentence) / 최종 소비 유형(typeName).
   각 라벨은 골드 소제목, 값은 진한 잉크색·기존보다 한 단계 큰 글씨.
2. 유형 카드: **axisCode 표기 제거.** 카드 중앙 텍스트 = typeName 한글명 **딱 한 줄**
   (단축판이라 최장 20자). 글자 수에 따라 폰트 자동 축소(JS로 길이 기반 font-size 계산,
   줄바꿈 금지 white-space: nowrap). 위치는 기존 코드 자리(top 67.7%)에 크게,
   기존 이름 자리(75.4%)는 비운다.
3. 법정 레이아웃 (데스크톱·발표 화면 기준):
   - 판사: 가운데 정렬 + 크게 (max-width 170→260px 수준)
   - 증거물 액자: 오른쪽 배치 유지하되 크게 (46%→52%, 판사와 겹치지 않게)
   - 판사 말풍선: 글씨 1.12rem→1.35rem, 선택지 버튼 글씨도 1.05rem 이상
4. 가독성:
   - 심증 게이지 라벨·"유력 용의 유형": 반투명 어두운 칩 배경 + 글씨 키우고 골드/아이보리로
   - 증거물 액자 캡션 "증거물 제1호": 크기·대비 상향 (배경 위에서 안 죽게)
   - 로딩 오버레이: 의사봉 아이콘·문구 2배 이상 크게 (발표장 뒷자리 기준)
5. **투명 배경 버튼 전면 제거**: .btn-ghost를 어두운 목재색 솔리드(+골드 테두리·골드 글씨)로
   교체 — 모든 화면 공통. 배경과 섞여 안 보이는 버튼이 하나도 없어야 한다.
6. 전과 상세 모달·기록 카드의 typeName도 새 단축판이 그대로 흐르는지 확인만.
