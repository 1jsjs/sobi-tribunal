[F310] 기소 예외 처리 — 상품 처리 실패 + 사진 제거 버튼

프론트만 수정 (index.html, app.js, style.css). 백엔드 무변경.

1. 상품 처리 실패 (비전이 상품을 못 뽑았을 때):
   - 현재 handleIntakeResult()는 dossier.itemName이 비면 "증거를 판독하지 못했소" 안내 후
     startManualEntry()로 수동 입력에 자동 진입한다.
   - 변경: 자동 진입하지 말고 **기소 화면에 남는다.** intakeNotice에
     "상품 처리 실패 — 증거에서 상품을 찾지 못했소. 사진을 제거하고 다른 사진을 올리거나,
     [자수하겠소]로 직접 적으시오." 를 띄운다. showScreen("intake") 유지.
   - 사용자가 스스로 고른다: 다른 사진 재제출 / [자수하겠소] 클릭.
2. 사진 제거 버튼:
   - 업로드 미리보기(upload-preview) 아래에 작은 버튼 [✕ 사진 제거] 추가 (id: btn-remove-photo,
     기본 hidden, 사진 선택 시 표시).
   - 클릭 시: pickedFile/pickedObjectUrl 정리(objectURL revoke), fileInput.value 초기화,
     미리보기·버튼 숨김, 증거 제출 버튼 disabled, 안내문 숨김.
   - 스타일: 작은 알약형, 우측 정렬, 우드 배경 + 도장색(--stamp) 테두리·붉은 글씨 —
     주 버튼과 확실히 구분되는 보조 파괴 액션 룩.
3. 회귀 주의: 사진 재선택(change) 시 이전 objectURL revoke는 기존 로직 유지,
   제거 후 재선택도 정상 동작해야 한다. F308 프리페치와는 무관(조서 화면 진입 전이므로).
