[F302] 소환장(이메일) + 기소(사진 업로드 / 수동 입력)

api-contract.md §POST /api/intake·§dossier 참조.

1. 소환장 화면:
   - "피고인 출석 확인" — 이메일 입력 1칸 + [출석하겠소] 버튼
   - 형식 검사(@·. 포함)만 클라에서, localStorage("defendantEmail")에 저장, 있으면 자동 통과
   - 안내 문구: "본 법정은 비밀번호를 요구하지 않소. 피고인의 양심을 믿소."
2. 기소 화면:
   - 큰 업로드 존: "증거를 제출하시오" — <input type="file" accept="image/*">
     (capture 속성은 넣지 말 것 — 갤러리 선택이 기본이 되도록)
   - 클라이언트 리사이즈: canvas로 최대 변 1568px, JPEG 품질 0.8로 변환 후 전송
     (원본 objectURL은 세션 동안 보관 — photoUrl null일 때 증거물 액자에 쓴다)
   - POST /api/intake (6~9초 → 로딩 "증거물 감식 중...")
   - candidates가 2건 이상이면 "어느 건으로 기소하시겠소?" 리스트(품목·금액·날짜) → 선택
   - candidates가 빈 배열이면 "증거를 판독하지 못했소" + 수동 입력 폼으로 유도
   - [자수하겠소(직접 입력)] 링크 → 수동 폼: 품목명/가격/산 날(선택)/카테고리(한글 셀렉트,
     값은 영문 코드)/한 줄 사연(선택) → 서버 호출 없이 dossier 객체 직접 구성
3. 완료 시 dossier + photoUrl(또는 objectURL)을 상태에 저장하고 조서 확인 화면으로

완료 기준: 사진 경로·수동 경로 모두 dossier가 만들어져 다음 화면으로 넘어간다.
큰 사진(5MB+ 원본)도 리사이즈 덕에 업로드가 통과한다.
